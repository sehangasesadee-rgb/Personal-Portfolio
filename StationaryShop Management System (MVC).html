Stationary Management System(MVC)

1. Project Core & Purpose

Objective: To develop a robust Desktop Application for Nadee Trading Company, focusing on business operations, inventory, or sales management.

Target Audience: This project is designed as a professional-grade software solution, likely part of an advanced software engineering module at IJSE.

2. Technical Framework (The Stack)

Java 11: Modern, scalable ecosystem. Maven: Build automation & dependency management. JavaFX 13: Layout-driven UI with FXML. ControlsFX: High-quality UI components & validation.

3. Key Project Components

Database: MySQL (via mysql-connector-j) for reliable data persistence.

Reporting: JasperReports v7.0.3 for generating invoices, receipts, and monthly reports.

Main Entry: Starts through lk.ijse.nadeetradingcompany.App class.

4. Setup & Execution

Import pom.xml into IntelliJ IDEA.

Maven Command: mvn clean javafx:run

Debugging: Uses JPDA via nbactions.xml.

Deployment: Prepared with jlink for distribution.

5. Development Strategy

Layered Architecture: Organised to separate concerns (UI, Business Logic, and Database Access).

Deployment: Prepared for custom Java Runtime Image creation using jlink for easy distribution.
