Connect-Four-Game

1. Project Core & Purpose

Objective: You are required to implement the complete back-end logic of the Connect-4 game, specifically focusing on the AI player's decision-making process.

Target Audience: This is a structured assignment for students at the Institute of Software Engineering (IJSE), specifically within the DEP (Direct Entry Program) framework.

2. Technical Framework (The Stack)

Language & Version: Java 11 (specified in the pom.xml compiler properties). Build Tool: Maven is used for dependency management and project lifecycle. Graphics (UI): JavaFX 18.0.2 provides the graphical user interface, supplemented by the JFoenix library for Material Design components. Deployment: The Maven Shade Plugin is configured to package the application into an executable "fat" JAR file.

3. Key Project Components

Logic Separation: The code is organized into packages, with lk.ijse.dep.service intended to house the core game services and AI logic.

Artifacts Ignored: The .gitignore file ensures that IDE settings (.idea/), build outputs (target/, out/), and compiled module files (*.iml) are not tracked.

Licensing: The project is released under the MIT License, which allows for free use and modification.

4. Setup & Execution Instructions

Cloning: Use Git to pull the repository from the GitHub source.

IDE Integration: Open the project via the pom.xml in IntelliJ IDEA.

Run Configuration: Create a Maven run configuration with the command javafx:run.

Java Version: A JDK 11 installation is strictly required.

5. Development Strategy

Starter Code: The repository provides the UI and the skeleton structure, but the actual "brain" of the game is left empty for you to implement.

External Documentation: Detailed task requirements are hosted externally on a Google Drive link provided in the documentation.
